# ХатаВойс на Mac и iPhone

Собрать программу для Apple можно только на macOS: Apple отдаёт свои инструменты сборки (Xcode, SDK) лишь для Мака. На этом ПК (Windows) проверяется только то, что весь Rust-код компилируется под Mac и iPhone: `packaging/apple-check`. Сама сборка идёт на Маке. Ниже три пути, от простого к сложному.

## Что уже готово

- **Rust-код** проверен для трёх целей: Mac на Apple Silicon (`aarch64-apple-darwin`), Mac на Intel (`x86_64-apple-darwin`) и iPhone (`aarch64-apple-ios`). Для iPhone пришлось положить в `third_party/` копии `netwatch` и `netdev` с небольшой правкой (см. `third_party/README.md`).
- **Mac:**
  - родные кнопки окна слева над нашей верхней полосой (`tauri.macos.conf.json`), сочетания клавиш через ⌘;
  - push-to-talk по глобальной клавише (`ptt_hook_mac.rs`, просит «Мониторинг ввода»);
  - «отошёл от компьютера» (`idle.rs`);
  - прозрачное окно для персонажей на рабочем столе (`macOSPrivateApi`).
- **iPhone:** звонок продолжается при заблокированном экране (фоновый звук в `Info.ios.plist`), разрешение на домашнюю сеть, отступы под вырез экрана (`viewport-fit=cover`).
- **Сборка на маках GitHub:** `.github/workflows/build.yml`. Для Mac — один универсальный `.dmg` для Intel и Apple Silicon. Для iPhone — `.ipa`: неподписанный или подписанный, если есть платный аккаунт разработчика.

## Путь 1. Маки GitHub (Мак не нужен)

1. Заведи **закрытый** (private) репозиторий на github.com.
2. В папке проекта выполни:

   ```bash
   git remote add origin https://github.com/<ты>/<репозиторий>.git
   ```

   ```bash
   git push -u origin main
   ```

   Ключи `vendor/` (подпись установщика, Android) в git не попадают: они в `.gitignore`.
3. На GitHub открой Actions → build → Run workflow. Через 20–40 минут на странице запуска появятся файлы `macos` (`.dmg`) и `ios` (`.ipa`).

У бесплатного аккаунта GitHub для закрытых репозиториев есть лимит минут, и минута на Маке считается за десять. Одной-двух сборок в месяц хватит.

**Mac без сертификата Apple.** У `.dmg` простая подпись (ad-hoc). Первый раз программу открывают правым кликом → «Открыть», дальше она запускается как обычно.

**iPhone без платного аккаунта.** Неподписанный `.ipa` ставится через Sideloadly (есть для Windows) или AltStore с твоим бесплатным Apple ID. Apple разрешает такую установку на 7 дней, потом её нужно повторить (Sideloadly и AltStore умеют обновлять сами). С платным аккаунтом разработчика (99 $ в год) добавь в настройках репозитория переменную `APPLE_TEAM_ID` и секреты из шапки `build.yml`: тогда сборка подписывается сразу.

## Путь 2. Мак друга

Проще всего — архив, который Мак собирает сам: `python scripts/pack-apple-friend.py` кладёт его в `dist/HataVoice-<версия>-Mac-iPhone.zip`. Внутри инструкция и два файла: «Собрать для Mac.command» и «Собрать для iPhone.command». Они сами ставят Rust, Node.js и pnpm в папку архива и собирают программу. Mac-версия получается без своего сервера, поэтому Go и LiveKit не нужны. iPhone-версия ставится на подключённый телефон через Xcode с бесплатным Apple ID. Скрипты лежат в `packaging/apple-friend/`.

Вручную на Маке нужны Xcode (из App Store), Rust (`rustup`), Node.js 22, pnpm и Go (для LiveKit). Затем:

```bash
cd client && pnpm install && pnpm tauri build --bundles dmg
```

На iPhone можно поставить прямо из Xcode с бесплатным Apple ID, тоже на 7 дней:

```bash
cd client && pnpm tauri ios init && pnpm tauri ios dev
```

## Путь 3. Свой Мак

То же, что путь 2, плюс можно отлаживать и проверять всё вживую.

## Что ещё не проверено

Ни один из этих пунктов не запускался на настоящем Маке или iPhone:

- **Шифрование звонков в WebKit.** LiveKit на Маке и iPhone шифрует кадры через `RTCRtpScriptTransform` (а не через Insertable Streams, как в Windows), и наш обработчик кадров (`e2eeWorker.ts`) этот путь поддерживает. Проверить без Мака нельзя: в WebKit из Playwright для Linux нет ни `RTCRtpScriptTransform`, ни поддельного микрофона (пробовал 2026-11-08). Первое, что стоит сделать на Маке, — позвонить с него другу на Windows и посмотреть на замок «Звонок зашифрован».
- **Показ экрана на Mac.** `getDisplayMedia` в WKWebView работает начиная с macOS 13.
- **Звонок в фоне на iPhone.** WebKit может приостанавливать микрофон, когда программа свёрнута.
- **Свой сервер на Маке.** LiveKit собирается из исходников в той же сборке.
- **Персонажи на рабочем столе поверх полноэкранных игр.** На Маке у каждой такой игры своё рабочее пространство.

## Чего на Mac и iPhone нет

- **Студия записи и стримов.** Ей нужен `MediaStreamTrackProcessor`, которого в WebKit пока нет. Пункт скрыт и появится сам, когда Safari его добавит.
- **Чужое управление этим Маком и виртуальные геймпады.** Они сделаны только для Windows. Самому управлять чужим ПК с Windows с Мака должно получиться (просящая сторона от системы не зависит), но это не проверялось.
- **На iPhone, как и на Android:** нет своего сервера, персонажей на рабочем столе и push-to-talk по глобальной клавише.
