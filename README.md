# ХатаВойс

**Голосовой мессенджер для своей компании, со своим сервером и сквозным шифрованием.**
Звук как в TeamSpeak, удобство как в Discord, а сервер — у тебя дома, и даже он не слышит ни слова.

## Что умеет

- **Свой сервер в один клик.** Сервер создаётся прямо из программы и работает на твоём ПК (или телефоне). Друзья заходят только по приглашению. Без белого IP — через P2P, Radmin VPN или ZeroTier.
- **Чистый голос.** Opus до 128 кбит/с, нейросетевой шумодав RNNoise, push-to-talk, голосовая активация, громкость каждого 0–200%, смена голоса на лету.
- **Демонстрация экрана** до 4K 60 к/с с кодированием на видеокарте (AV1, H.264), со звуком окна или всего ПК, и вебкамера.
- **Чат** с файлами до 2 ГБ, реакциями, ответами, упоминаниями, голосованиями и голосовыми сообщениями. Личные сообщения и закрытые каналы.
- **Фоторедактор и видеоредактор** перед отправкой: слои, кисти, текст, коррекция и фильтры; монтаж с дорожками, скоростью, титрами.
- **3D-персонажи** на сцене звонка: открывают рот в такт голосу, показывают эмоции и могут стоять поверх игры на рабочем столе. Можно загрузить свою модель VRM.
- **Вместе:** совместный просмотр YouTube и сайтов, музыка друг другу, доска для рисования, игра одним геймпадом на двоих (split-screen), удалённое управление ПК друга с его разрешения.
- **Студия как OBS:** запись и стрим на Twitch, YouTube или свой RTMP.
- **Роли, права и модерация**, которые нельзя подделать: каждое действие подписано ключом того, кто его сделал.
- **Темы, рамки аватарок, режим стримера**, проверка скорости и проверка файлов на VirusTotal.

## Установка

**Windows 10/11.** Скачай `HataVoice_…_x64-setup.exe` со страницы [релизов](../../releases/latest) и запусти. Права администратора не нужны, свой сервер ставится вместе с программой.

> Установщик пока без цифровой подписи, поэтому Windows может показать «Windows защитила ваш компьютер». Нажми «Подробнее» → «Выполнить в любом случае».

**Android 8+.** Скачай `HataVoice_…_android-arm64.apk` и установи (Android попросит разрешить установку из этого источника).

Обновления приходят через сервер, на котором ты сидишь: программа проверяет подпись издателя и не поставит подменённый файл.

## Свой сервер

В программе: «+» в колонке серверов → «Создать свой». Сервер запускается на этом ПК, сам поднимает голосовой сервер LiveKit и пытается открыть порты через UPnP. В «Настройки сервера → Подключение» видно, как к тебе попасть и что мешает.

| Порт | Протокол | Зачем |
|---|---|---|
| 7350 | TCP | Подключение к серверу (TLS 1.3) |
| 7882 | UDP | Голос и видео |
| 7881 | TCP | Голос, если UDP закрыт |

Нет белого IP — включи P2P (работает через промежуточный узел, он видит только шифр) или соберитесь в Radmin VPN / ZeroTier: программа сама найдёт адрес в такой сети.

## Безопасность

- **Звонки** шифруются сквозным ключом, который есть только у людей в канале: группа MLS на каждый звонок с постквантовым шифронабором X-Wing. Сервер, даже взломанный, слышит только шифр.
- **Чат и файлы** — тоже сквозное шифрование (MLS, у каждого файла свой ключ XChaCha20-Poly1305). Сервер хранит только шифротекст.
- **Подключение к серверу** — TLS 1.3 с постквантовым обменом X25519MLKEM768; сертификат сверяется с ключом сервера из приглашения, подмену программа видит.
- **Личность** — ключ Ed25519 на твоём ПК под защитой Windows (DPAPI); роли, баны и журнал действий подписаны и проверяются каждым.
- В окне звонка есть код из цифр: сравните его вслух — если совпал, посередине никого.

Что сервер всё-таки видит (кто и когда в сети, размеры сообщений, IP-адреса), честно описано в [docs/protocol.md](docs/protocol.md). Нашёл уязвимость — напиши, см. [SECURITY.md](SECURITY.md).

## Сборка из исходников

Нужны Rust (stable, MSVC), Visual Studio Build Tools с C++, Node.js LTS и pnpm.

```bash
powershell -ExecutionPolicy Bypass -File scripts/get-livekit.ps1
cargo build -p hatavoice-server
cd client
pnpm install
pnpm tauri dev
```

Установщик целиком: `powershell -ExecutionPolicy Bypass -File scripts/build-installer.ps1`. Android собирается в Docker: `packaging/android`.

Тесты: `cargo test --workspace` и `cd client && pnpm exec vitest run`.

| Папка | Что там |
|---|---|
| `client/` | Программа: Tauri 2 + React + TypeScript (`src` — интерфейс, `src-tauri` — Rust) |
| `server/` | Сервер `hatavoice-server` (Rust, axum) |
| `crates/` | Журнал участников и роли, TLS, сквозное шифрование, P2P, хостинг |
| `packaging/` | Сборка для Android, Linux, macOS и iOS |
| `docs/` | Протокол и разбор безопасности |
