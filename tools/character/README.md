# Персонажи с нуля

«Рэн», «Мира» и «Кай» (`client/public/avatars/ren.vrm`, `mira.vrm`, `kai.vrm`) собраны здесь из кода, без готовых моделей: Blender в фоне
строит геометрию, скелет, веса и выражения, а `vrm.py` делает из этого VRM 1.0. Ничего ставить в Blender не нужно.

```
blender -b --factory-startup --python build.py -- out/ren.glb
python vrm.py out/ren.glb out/ren.vrm --name Рэн
blender -b --factory-startup --python build_mira.py -- out/mira.glb --preview out/pv
python vrm.py out/mira.glb out/mira.vrm --name Мира
```

У «Миры» свои тело, одежда и волосы (`mira.py`: свободное худи с капюшоном и шнурками, шорты поверх легинсов, кеды,
наушники на шее, каре с мятными кончиками), а скелет, лицо и выражения — общие с «Рэном», поэтому все движения программы
подходят ей сразу. `--preview` кладёт картинки со всех сторон (EEVEE). `emoji_headphones.py` рисует значок 🎧 эмоции
«Диджей».

«Кай» (`kai.py`, `build_kai.py`, `kai.vrm`): бомбер с резинками в полоску, карго с карманами, высокие кеды, шапка-бини
с отворотом поверх короткой стрижки. Тот же скелет и то же лицо.

```
blender -b --factory-startup --python build_kai.py -- out/kai.glb --preview out/pv
python vrm.py out/kai.glb out/kai.vrm --name Кай
```

Картинка для галереи (`<id>.webp`) — движком программы: `client/portrait-lab.html`.

### Искра

Малая панда в лётной куртке, с гарнитурой и почтовым приёмником за спиной. В мастерской она находится в разделе «Герои».
У неё три собственных варианта эмоций. «Помахать» запускает приветствие с подмигиванием, «Позвать» — ответ по рации,
«Танец» — почтовый свинг. Остальные действия и речь работают через общий скелет и выражения VRM.

В [сцене Blender](iskra/Iskra.blend) есть четыре подписанных действия на дорожке NLA. Пробел запускает их по очереди.
В [ролике](iskra/Iskra.mp4) можно посмотреть движения и круговой обзор. Рисунок шерсти упакован в модель и сцену.
Команда для пересборки модели из корня проекта

```sh
blender -b --factory-startup --python-exit-code 1 --python tools/character/iskra/build.py
```

Сборка записывает `tools/character/iskra/Iskra.blend` и `client/public/avatars/iskra.vrm`.
Позы и тайминг для Blender и клиента общие, в `client/src/characters/iskra-motions.json`. Углы указаны в градусах, время — в секундах.
Для просмотра на сцене запустите `pnpm dev` в папке `client` и откройте `/character-lab.html?gallery=iskra&mode=preview&acts=wave,call,dance`.

Что где:

- `lib.py` — лофты по сечениям, слияние вокселями, сглаживание, «наклейки» по поверхности, материалы (цвета в sRGB).
- `body.py` — тело одной поверхностью (торс, руки, мешковатые штаны), кисти с пальцами, сапоги. Размеры в метрах, лицом к −Y.
- `head.py` — череп из срезов, глазницы (булево вычитание), лицо: белки, радужки, веки, ресницы, брови, рот, зубы, язык.
  Каждое выражение — ключ формы с именем выражения (`happy`, `blink_L`, `aa`, `lookLeft`…), VRM связывает их по имени.
- `hair.py` — шапочка и пряди: прядь ложится на голову по кривизне и отрывается к кончику; макушка — «черепица» от вихра;
  хвостик на своей цепочке костей. У прядей бывают свои `follow` (сколько лежит на голове), `blunt` (прямой срез, как у
  каре) и `uv` (какая часть цвета вдоль пряди).
- `garments.py` — зоны одежды на теле (кожа, топ, штаны), воротник, канты, пояс с бантом и концами, шарф с хвостами,
  бинты, перчатки, сетчатая майка.
- `gear.py` — меч за спиной, ремень через грудь, наплечник.
- `rig.py` — скелет с именами костей VRM, веса: тепловые для тела, по отрезкам костей для кистей и стоп, перенос с тела на одежду.
- `vrm.py` — гуманоид, выражения, взгляд выражениями, пружинящие кости (коллайдеры задаются в координатах Blender), MToon.
- `preview.py`, `try_*.py` — быстрые картинки частей (Workbench/EEVEE) при правке.

У Рэна, Миры и Кая анимации общие (motion capture, эмоции, действия вдвоём); своё у модели — пружинящие хвост,
шарф и концы пояса.
